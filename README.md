# IELTS Band 6.5-7 Preparation Plan

## Target
- **Primary**: Band 6.5
- **Stretch**: Band 7.0
- **Timeline**: 1-2 months

## Current Estimated Scores
| Skill | Band | Notes |
|-------|------|-------|
| Reading | 6.5 | Good comprehension, focus on speed |
| Listening | 6.5 | Good understanding of clear speech |
| Writing | 6.0 | Confident but slow, need speed |
| Speaking | 5.5-6.0 | Confident for 1 min, need 2-3 min fluency |

## The Gap (6.0 → 6.5)
- **+0.5 Writing**: Speed (150 words/20min → 150 words/18min) + Task Achievement
- **+0.5-1.0 Speaking**: Extend answers, reduce hesitation, vocabulary range

## Weekly Focus (7-14 hours)
1. **Speaking** (30-40% of time) - Priority area
2. **Writing** (25-30%) - Speed + Task response
3. **Vocabulary** (20%) - Academic words, collocations
4. **Reading/Listening** (10-15%) - Maintenance

## Daily Schedule
- Morning: 30 min Vocab/Grammar flashcards
- Evening: 1 hour focused practice (rotate skills)
- Weekend: 1-2 hours Speaking + Mock test
